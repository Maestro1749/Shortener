# Shortener

Гибридный сервис для сокращения ссылок, написанный на Go с использованием слоистой архитектуры. Изначально разрабатывался как REST API, после чего был успешно расширен поддержкой gRPC для практики работы с протоколом и кодогенерацией.

## Функционал
* Создание короткой ссылки (REST / gRPC)
* Редирект на оргинальный URL
* Получение оригинального URL по хэшу
* Обработка дубликатов (одна ссылка - одна короткая ссылка)

## Стек
* Язык: Go
* Протоколы: REST API, gRPC (Protocol Buffers v1)
* Инструменты Protobuf: Buf CLI
* База данных: PostgreSQL + golang-migrate
* Логирование: Uber Zap
* Инфраструктура: Docker, Docker Compose 

## Архитекура

Проект основан на слоистой архитектуре:

**handler -> service -> repository**

**Handler** - работа с HTTP

**Service** - бизнес-логика

**Repository** - работа с БД

**Models** - структуры данных

### Запуск проектаПроект полностью контейнеризирован и запускается одной командой (база данных, миграции и само приложение поднимутся автоматически):
`docker compose up --build`

### После запуска:
HTTP REST доступен на порту :8080 (или вашем APP_PORT)
gRPC Сервер принимает запросы на порту :50051 (или вашем GRPC_PORT)
